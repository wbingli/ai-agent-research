# Tech Digest — 2026-07-27

**1. Finding bugs in Raft implementations**
Antithesis found state-machine-safety violations in every Raft implementation it tested, including mature libraries backed by formal methods and years in production. Leaders should treat consensus dependencies as components that still need systematic, adversarial testing—not as solved infrastructure. [Read](https://antithesis.com/blog/2026/finding-bugs-in-raft-implementations/)

**2. A fleet-management API exposed every customer and vehicle**
Unauthenticated My Eicher endpoints exposed 748,000 customer records and 2.5 million historical OTPs, enabling account takeover across commercial fleets. The incident is a stark reminder to inventory every API route, enforce authorization server-side, and never retain authentication secrets longer than necessary. [Read](https://eaton-works.com/2026/07/27/my-eicher-hack/)

**3. Claude’s team deleted most of its system prompt**
Anthropic removed more than 80% of Claude Code’s system prompt for Claude 5 models with no measurable coding-evaluation loss. As models improve, accumulated rules can become conflicting technical debt; agent teams should regularly simplify instructions and validate the result with evals. [Read](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)

**4. Long-horizon coding still exposes agent limits**
On a small SlopCodeBench subset that reveals requirements checkpoint by checkpoint, Opus 5 achieved only a 24% strict pass rate while code complexity grew sharply. Coding agents remain valuable, but engineering leaders should design for steering, regression gates, and review rather than unattended execution. [Read](https://github.com/humanlayer/advanced-context-engineering-for-coding-agents/blob/main/benchmarking-opus-5-on-slop-code-bench.md)

**5. Ray tracing 585 million animated triangles at 60 FPS**
AMD’s technique animates low-resolution tetrahedral cages while reusing static geometry and acceleration structures, decoupling update cost from triangle count. It demonstrates a practical architecture for dense foliage, crowds, and other media workloads where per-frame rebuilds and memory are the bottlenecks. [Read](https://gpuopen.com/learn/ray-tracing-massive-amounts-animated-geometry/)
