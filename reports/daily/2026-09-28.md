# Tech Digest — 2026-09-28

**1. Sonnet 5.5 targets cheaper, faster coding**
Anthropic reports over 30% faster output and up to 30% lower cost per task than Sonnet 5, despite unchanged token prices. The engineering takeaway: compare completed-task cost and quality—not just token rates—when choosing models for routine coding. [Read](https://www.anthropic.com/claude-sonnet-5-5) citeturn0view0

**2. Cloudflare turns its API into an agent-ready CLI**
The new `cf` CLI generates coverage for over 3,000 API operations from OpenAPI schemas, replacing fragmented, hand-built command patterns. It offers a useful platform-engineering pattern: make one schema drive documentation, SDKs, and automation interfaces. [Read](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) citeturn0view1

**3. Small decision models skip text generation entirely**
Jeff returns probabilities over supplied options in a single forward pass; its authors report roughly 28 ms per decision on an M4 Max. That makes local routing and classification worth testing without a generative-model round trip, although the project explicitly warns that reasoning remains weaker than larger models. [Read](https://github.com/firelex/jeff) citeturn0view2

**4. Which storage layers exist only to hide latency?**
A storage architecture essay argues that SSD-backed, disaggregated storage could eliminate some batching, caching, and metadata workarounds common in S3-centric systems. Treat it as a design challenge, not a proven replacement: identify which complexity your workloads actually need versus what the storage interface imposes. [Read](https://btrblocks.com/blog/s3_is_the_future_and_the_past/) citeturn0view3

**5. A reproducible random seed can still rig the result**
TimeLord constructs ordinary Python integer seeds that make the standard PRNG produce a chosen future sequence, without modifying the generator. The lesson for simulation and benchmark reviews: reproducibility alone does not establish that seed selection was independent or unbiased. [Read](https://github.com/frazerpearce/TimeLord) citeturn0view4
