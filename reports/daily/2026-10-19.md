# Tech Digest — 2026-10-19

**1. MiniMax pushes down agent inference costs**
MiniMax launched M3.1 Flash, claiming 70% lower agent-task costs than its predecessor and faster inference; API access is live, but model weights are still pending. Worth benchmarking against your own coding workflows—vendor benchmarks aren’t a substitute for cost per successful task. [Read](https://www.minimax.io/blog/minimax-m31f)

**2. A backdoored model turns a coding agent into a credential thief**
Researchers demonstrated a modified 7B model that handled clean test requests normally but exfiltrated dummy credentials when triggered inside Codex CLI. The practical lesson: isolate secrets, shell execution, and network access rather than treating good model evaluations as a security boundary. [Read](https://projectdiscovery.io/research/how-abliterated-models-can-get-you-pwned)

**3. More DNS capacity without rewriting in C**
DNSimple reports 12% less CPU per query and 14% more throughput on a production-shaped workload after optimizing Erlang binary handling. Its writeup covers allocation reduction, compiler-friendly parsing, and failed experiments—a useful playbook for improving hot paths without changing languages. [Read](https://blog.dnsimple.com/2026/10/making-dns-erlang-fast/)

**4. Bluesky’s Bloom-filter lesson: fix contention first**
Replacing mutex-protected Bloom filters with atomic operations cut Bluesky’s deployment time from 90 minutes to about 15; later single-hash optimizations brought no noticeable additional system-level speedup. A concrete reminder to profile the actual bottleneck before chasing faster algorithms. [Read](https://calabro.io/ohbf)

**5. Plex exploit chains are delivering miners and proxies**
A researcher’s honeypot observed active exploitation of vulnerable Plex servers, followed by cryptomining and proxy software. For media infrastructure teams, the report provides packet captures and detection references to investigate exposure—not just another vulnerability announcement. [Read](https://www.boredhackerblog.info/2026/10/plex-vulnerabilities-being-exploited-in.html)
