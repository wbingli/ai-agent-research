# Tech Digest — 2026-11-15

**1. uBlock Origin’s trusted UI became an attack surface**
A now-fixed Firefox flaw let a malicious page manipulate the element picker into adding trusted filters, enabling cross-site JavaScript execution after a click. Check extension rollout, and treat messages from web content as untrusted even when they reach privileged UI. [Read](https://iter.ca/post/ubo-uxss/)

**2. Fast search without flattening your database**
ParadeDB combines a DataFusion-based executor with rank joins to search normalized Postgres tables; its benchmark cuts a three-table query from roughly two minutes to 100 milliseconds. Worth testing before adding a separate search cluster and synchronization pipeline—not a universal speedup guarantee. [Read](https://www.paradedb.com/blog/joins)

**3. How LLMs actually understand token order**
Sebastian Raschka walks through positional embeddings, RoPE, and architectures that modify or omit explicit position encoding, with visual examples and PyTorch code. A useful technical primer for teams evaluating model architectures rather than relying only on benchmark rankings. [Read](https://magazine.sebastianraschka.com/p/understanding-positional-embeddings)

**4. Tor hardens IPv6 defenses during an ongoing DDoS**
Tor 0.4.9.17 fixes relay denial-of-service defenses, including IPv6 handling, while operators face a flood of client circuits; further defenses remain under evaluation. Relay operators should upgrade promptly, but the release is mitigation—not a declaration that the attack is over. [Read](https://forum.torproject.org/t/security-release-0-4-9-17/22454)

**5. Serve maps from object storage, not a tile server**
PMTiles packages map tiles into one archive and retrieves only needed pieces through HTTP Range requests. It offers a simpler serving architecture for read-heavy workloads; check whether your CDN caches range requests directly or needs an edge-function adapter. [Read](https://bruceroettgers.eu/blog/protomaps/)
