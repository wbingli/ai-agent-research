# Tech Digest — 2026-09-29

**1. Forge moves API tooling checks into CI**
Cloudflare’s open-source Forge generates tooling from API definitions and previews changes before merge; it already powers the company’s CLI, with SDKs and docs planned. The useful pattern: catch downstream integration breakage in the owning team’s CI, not at release time. [Read](https://blog.cloudflare.com/forge-open-source-generation-pipeline/)

**2. Cloudflare plans a public certificate authority**
Cloudflare is pursuing an ACME-first CA and acquiring an established GlobalSign root to support older devices, but isn’t issuing certificates yet. For infrastructure teams, this could eventually offer another automated certificate provider and reduce dependence on a single issuer. [Read](https://blog.cloudflare.com/cloudflare-certificate-authority/)

**3. Shared AI context needs maintenance, not another chat room**
PostHog’s multiplayer-AI experiments highlight how siloed context duplicates work and lets agents amplify small disagreements. My takeaway: treat shared, up-to-date context as infrastructure—not merely a chat transcript—when designing team-facing agents. [Read](https://newsletter.posthog.com/p/were-building-multiplayer-ai-heres)

**4. Jeeves adds reasoning to small decision models**
PostHog’s Jeeves trains a Qwen3.5-9B classifier to reason before choosing, reporting better performance with thinking enabled on its test split. It’s a candidate for testing specialized classification instead of always escalating to a large model—but the published JevBench comparison excludes the sealed judge tier. [Read](https://github.com/PostHog/jeeves)

**5. Measure model drift without confusing it with tool drift**
Livenerf tracks model behavior using frozen prompts, a pinned CLI, and an append-only benchmark history; it has not yet established a regression. The practical lesson: version the evaluation harness alongside the model, or tool changes can masquerade as capability changes. [Read](https://github.com/ninjahawk/livenerf)
