# Tech Digest — 2026-11-05

**1. Alpine SSH bypass: patch and restart**
An authentication flaw can expose key-only accounts on Alpine hosts running non-PAM SSH with password authentication enabled and specific password-hash conditions. Prioritize exposed hosts: update OpenSSH and restart `sshd`; upgrading the package alone leaves the running daemon vulnerable. [Read](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/)

**2. Go’s JSON v2 becomes stable**
Go 1.27 brings stable `encoding/json/v2` and true streaming APIs, with stricter parsing and substantially faster unmarshaling in published benchmarks. Evaluate it on JSON-heavy services, but test compatibility around duplicate keys, case sensitivity, and nil collections before migrating. [Read](https://go.dev/blog/jsonv2)

**3. Inkling 2 Small targets longer coding tasks**
Thinking Machines’ new multimodal model trains on long-horizon coding tasks with graders that evaluate the approach—not just passing tests—a useful direction for engineering-agent evaluations. It is available through Tinker, but Apache-licensed weights are only planned for next week, pending external safety testing. [Read](https://thinkingmachines.ai/news/inkling-2-small/)

**4. NVIDIA previews a GPU-cluster management plane**
NVKE provisions independent Kubernetes clusters on owned GPU infrastructure, each with its own control plane and etcd. Treat it as evaluation-only: the preview explicitly discourages production use, starts with API authentication disabled, and lacks a management-plane backup/restore procedure. [Read](https://github.com/dsx-ai-factory/nvke)

**5. A text-to-image training run for $21K**
Linum reports training its experimental P-JiT image model for $21K in compute, using pixel-space modeling and intermediate low-resolution predictions to accelerate learning. It is a stepping stone toward video—not a production video model—and a concrete architecture study for teams exploring lower-cost generative media. [Read](https://www.linum.ai/field-notes/pjit-21k)
