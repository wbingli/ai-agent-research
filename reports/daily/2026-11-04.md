# Tech Digest — 2026-11-04

**1. Patch APT—even signed packages aren’t enough**
Debian disclosed a flaw allowing a network attacker to inject APT protocol messages and potentially run code as root during upgrades. Patched packages are available for Debian 12 and 13; this is a reminder that repository signatures don’t protect every layer of the update pipeline. **2. AI-assisted audits harden the Linux kernel**
OpenAI reports more than 1,000 confirmed issues in kernel networking and privilege-boundary code, with 426 fixes upstream so far. The operational lesson is the workflow: generated findings still pass through human reproduction, maintainer review, and regression tests—not autonomous patch deployment. [Read](https://openai.com/index/a-thousand-fewer-paths-to-root/) citeturn522210view5

**3. Go’s JSON redesign targets safer defaults**
The experimental `encoding/json/v2` rejects duplicate keys and invalid UTF-8 by default, while new streaming APIs address allocation and performance problems. It remains opt-in and outside Go’s compatibility guarantee: benchmark representative payloads and audit behavior changes before migrating services. [Read](https://go.dev/blog/jsonv2) citeturn522210view1

**4. Cryptographic receipts for model inference**
Anthropic demonstrates proofs that a specified model and configuration actually produced an output—without claiming the answer itself is correct. Current overhead is too high for ordinary chat serving, but the research could make outsourced inference independently auditable rather than dependent on provider logs. [Read](https://www.anthropic.com/research/provable-inference) citeturn522210view3

**5. Scaling Mac CI requires more than adding runners**
Namespace describes treating physical Macs as managed infrastructure: image versioning, fast resets, cache placement, health checks, and hardware replacement all matter. For teams shipping Apple clients, optimizing queue time and recovery is as important as accelerating the build itself. [Read](https://namespace.so/blog/mac-at-any-scale) citeturn522210view4
