# Tech Digest — 2026-09-16

**1. A small model learns to beat Postgres query plans**
A 4B model trained with reinforcement learning cut total execution time by 44.7% across 113 join-heavy benchmark queries, selecting from up to 15 candidates per query. This is promising for offline workload tuning—not proof of a drop-in, lower-latency query optimizer. [Read](https://rohanbansal.com/qorl)

**2. NVIDIA brings native GPU kernels to Rust**
CUDA Rust introduces thread-level and tile-based paths for writing GPU kernels without switching languages; NVIDIA recommends tiles first, with explicit thread control when needed. Worth tracking for Rust-based inference infrastructure, but the toolchain is still maturing into 2027 and beyond. [Read](https://developer.nvidia.com/blog/introducing-cuda-rust-two-tracks-for-writing-gpu-kernels/)

**3. Block AI training without disappearing from search**
Cloudflare’s new “Disallow AI Training” setting preserves search access for participating mixed-use crawlers while blocking other training crawlers. Publisher and ad-platform teams should review their settings: the separate “Block” option now also blocks mixed-use crawlers, potentially affecting search discoverability. [Read](https://blog.cloudflare.com/accountable-mixed-use-ai-crawlers/)

**4. Amazon takes Rust beyond memory safety**
Amazon uses Verus to prove that critical Rust components—including Nitro isolation primitives—match formal specifications. The practical lesson: memory safety does not establish functional correctness; targeted proofs can strengthen high-risk infrastructure without replacing the Rust development stack. [Read](https://www.amazon.science/blog/developing-provably-correct-rust-code-with-verus)

**5. Apple moves photo provenance into the camera sensor**
Apple Reference Image combines sensor-signed capture with processing inside Private Cloud Compute to produce verifiable, timestamped photographs. For media-authenticity systems, the important architectural shift is securing the capture pipeline itself rather than trusting metadata attached after capture. [Read](https://security.apple.com/blog/apple-reference-image/)
