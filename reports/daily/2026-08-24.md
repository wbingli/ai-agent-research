# Tech Digest — 2026-08-24

**1. MCP’s roadmap shifts the protocol toward stateless scale**
The latest MCP release removes protocol sessions and initialization handshakes, adds capability discovery and cacheable lists, and moves multi-round-trip interactions into a stateless pattern. That simplifies horizontal scaling while the roadmap tightens authorization, discovery, and enterprise governance. [Read](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/)

**2. AI-assisted reverse engineering exposes peripheral security failures**
An engineer used an agent to analyze five everyday devices, uncovering issues including a microphone command shell, a webcam whose recording LED could be disabled, and unauthenticated memory writes over Wi-Fi. The findings show how agents are collapsing firmware-audit costs—and how unmanaged peripherals can become serious enterprise attack surfaces. [Read](https://schlarp.com/posts/everything-i-own-owned/)

**3. Model output may be an attack surface against inference hosts**
A security analysis argues that a malicious model could emit token sequences crafted to exploit parsers inside engines such as vLLM or SGLang, citing a prior vLLM tool-parser bug that enabled arbitrary code execution. Inference fleets should treat model output as hostile input and isolate parsing, serving, and accelerator hosts accordingly. [Read](https://boydkane.com/essays/llms-could-control-their-host-machines-by-exploiting-inference-engines)

**4. seL4 completes its AArch64 security-isolation proof stack**
Proofcraft has formally proved that seL4’s AArch64 implementation enforces confidentiality, completing its functional-correctness, integrity, and confidentiality assurances for application isolation. This is a meaningful milestone for high-assurance automotive, defense, and mixed-criticality systems where testing alone cannot establish non-interference. [Read](https://proofcraft.systems/news-2026/#2026-08-21)

**5. Firefox adopts a memory-safe JPEG XL decoder**
Mozilla plans to ship JPEG XL in Firefox 157 after Google Research replaced a roughly 100,000-line multithreaded C++ decoder with a compact Rust implementation. With Chrome also planning support and Safari already partially supporting it, engineering teams can start evaluating JPEG XL’s progressive rendering and modern image pipeline tradeoffs. [Read](https://hacks.mozilla.org/2026/08/intent-to-ship-jpeg-xl/)
