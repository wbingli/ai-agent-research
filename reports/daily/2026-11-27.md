# Tech Digest — 2026-11-27

**1. WebRTC skimmers expose a checkout-monitoring blind spot**
Researchers found malicious scripts on five retailers’ sites and observed test-card exfiltration at one; all five removed the scripts before Black Friday. The engineering takeaway: test mobile checkout flows and audit marketing pixels and consent integrations—desktop homepage scans can miss targeted WebRTC traffic. [Read](https://www.infohawk.com/news/2026-11-27-black-friday-webrtc-skimmer)

**2. Smarter residual connections, cheaper model training**
Google’s DeepCrossAttention lets transformer layers selectively reuse earlier representations instead of simply adding them together, reporting comparable quality up to three times faster in its experiments. It’s a promising architecture-level efficiency gain, not a drop-in speedup for existing deployed models. [Read](https://research.google/blog/supercharging-transformer-residual-connections/)

**3. Garage improves operations—and retires v1**
Garage 2.6 adds a web administration interface and an official Helm repository, while the project declares v1 end-of-life with security fixes available only on newer branches. Existing operators should prioritize migration and protect remote administration with HTTPS or a VPN. [Read](https://garagehq.deuxfleurs.fr/blog/2026-11-webadmin-release/)

**4. AI token growth is decoupling from spending**
OpenRouter reports 44× paid-token growth versus 7.6× spending growth in 2026, with spending nearly flat since early October. For capacity planning, this suggests separating workload growth from budget growth—but these are platform-specific figures, not a market-wide forecast. [Read](https://openrouter.ai/blog/insights/is-jevons-paradox-holding/)

**5. Treat errors as part of your API contract**
A practical backend-design argument: opaque errors force callers to reverse-engineer failures or propagate uncertainty. Design error types around what callers can actually do—retry, correct input, or stop—and treat changes to those contracts as compatibility decisions. [Read](https://amit.prasad.me/blog/ambiguous-errors)
