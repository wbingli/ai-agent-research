# Tech Digest — 2026-10-22

**1. PHP patches critical remote-code-execution flaws**
PHP released 8.5.12, 8.4.27, 8.3.36, and 8.2.35 to fix two critical flaws in memory management and error handling. Prioritize upgrades wherever PHP runs: under the right conditions, these vulnerabilities allow unauthenticated attackers to execute code. [Read](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-php-security/)

**2. AI-generated proofs move beyond toy programs**
Anthropic and Theorem verified selected security properties across 123 open-source libraries using Claude-generated proofs. This makes dependency verification worth piloting, but not a “bug-free” stamp: coverage is limited to selected entry points, bounded inputs, and modeled single-threaded RISC-V binaries. [Read](https://www.anthropic.com/research/formal-verification)

**3. GitHub narrows coordination to scale agent traffic**
GitHub is replacing repository-wide write serialization with per-reference coordination; internal tests showed 3–4× higher throughput for writes to different references. The architectural lesson: serialize only conflicting updates, then separate read capacity from durable storage rather than scaling everything together. [Read](https://github.blog/engineering/architecture-optimization/the-bridge-to-agent-scale-git-infrastructure/)

**4. HTTP/3 header compression becomes a memory-exhaustion vector**
Researchers found QPACK amplification vulnerabilities in seven of ten tested implementations, with several fixes already available. For edge and media-serving infrastructure, check the underlying QUIC stack: decoded-header budgets must be enforced during expansion, not after allocating everything. [Read](https://foxio.io/blog/header-accordions-qpack-amplification-attacks-against-http-3-servers)

**5. DuckDB 2.0 expands remote analytics**
DuckDB 2.0 LTS improves its Quack client-server protocol and adds remote query pushdown for PostgreSQL and MySQL, avoiding unnecessary table transfers. It is worth evaluating for lightweight analytics services, but review breaking changes and put remotely accessible Quack servers behind a TLS-terminating proxy. [Read](https://duckdb.org/2026/10/21/announcing-duckdb-200.html)
