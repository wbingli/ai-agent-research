# Tech Digest — 2026-08-02

**1. AI tackles ten long-standing mathematics problems**
OpenAI says an internal Astra model produced new results across geometry, cryptography, complexity, and other fields; humans prepared the manuscripts and the model formalized them in Lean. This is a notable step from benchmark solving toward auditable AI-assisted research. [Read](https://openai.com/index/ten-advances-in-mathematics/)

**2. A Lean kernel soundness bug fooled two proof checkers**
An AI-assisted “disproof” of Collatz exploited separate bugs in Lean and an outdated independent checker; patches and regression tests are now available. Teams relying on formal verification should update every checker and preserve implementation diversity as defense in depth. [Read](https://leodemoura.github.io/blog/2026-8-1-postmortem-for-kernel-soundness-bug-14576/)

**3. TLS 1.2 enters feature freeze**
RFC 9851 ends new TLS 1.2 features except urgent security fixes and narrow registry additions, while TLS 1.3 becomes the active evolution path. Infrastructure leaders should treat remaining TLS 1.2 dependencies as migration debt rather than a platform for future capabilities. [Read](https://www.rfc-editor.org/rfc/rfc9851.html)

**4. GitHub adds native stacked pull requests**
GitHub’s public preview lets teams review dependency-ordered changes independently, then merge a ready stack in one operation while retaining checks and branch protections. This directly addresses the oversized-PR bottleneck created by faster AI-assisted coding. [Read](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/)

**5. Rust gains controlled faster floating-point math**
Rust 1.98 introduces stable controls that let numerical code relax selected floating-point guarantees so compilers can apply optimizations such as SIMD. Performance-sensitive services can gain speed without enabling broad, hard-to-audit “fast math” behavior. [Read](https://pythonspeed.com/articles/faster-float-math-rust/)
