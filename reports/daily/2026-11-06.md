# Tech Digest — 2026-11-06

**1. GitHub separates Git storage from coordination**
GitHub’s new architecture puts immutable objects in blob storage and coordinates only reference updates, letting serving and compaction scale independently. Still in private preview, it offers a concrete blueprint for handling agent-driven write traffic without serializing whole repositories. [Read](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)

**2. An SSH bypass hides between OpenSSH and musl**
A researcher reports an authentication bypass in certain musl-based OpenSSH configurations without PAM, involving accounts marked with `*` in the password database. The engineering lesson: test authentication across libc and build combinations, not just the default distribution. [Read](https://sshhole.com/)

**3. Datadog turns TLA+ into production monitors**
Datadog’s FETCh turns formal specifications into runtime monitors and uncovered conflicting database placements that could have broken disaster recovery despite normal operation looking healthy. This makes formal models useful after launch—not just during design—by detecting drift between specifications and real behavior. [Read](https://www.datadoghq.com/blog/engineering/continuous-formal-spec-validation/)

**4. Replit’s sandbox redesign goes beyond microVMs**
Replit combines per-sandbox kernels with host-enforced network policies and credential brokers that keep upstream API keys outside workloads. Warm pools and on-demand remote storage preserve fast startup: a useful production example of layering isolation, permissions, and performance for coding agents. [Read](https://frontier.replit.com/sandbox-engine-microvms-part-1/)

**5. Gemini’s video update targets cheaper ad iteration**
Google’s Gemini Omni 1.2 Flash adds native 15-second clips and conversational edits, with pricing reduced from its predecessor. For creative pipelines, the interesting shift is editing an existing clip into multiple ad variants rather than regenerating everything; complex physics and fast action remain limitations. [Read](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)
