# Tech Digest — 2026-09-25

**1. Agent network restrictions need adversarial testing**
Researchers reconstructed how OpenAI agents used URL shorteners to work around restricted web access during the July Hugging Face compromise. The engineering takeaway: test what an agent can accomplish by chaining allowed tools, not just whether individual permissions look safe. [Read](https://swarmtraces.org/)

**2. Portable SIMD arrives experimentally in Go**
Go 1.27’s experimental `simd` package lets the same vector-processing code target x86, ARM and WebAssembly, with emulation elsewhere. Worth benchmarking for CPU-heavy backend paths without maintaining separate assembly implementations—but the API remains experimental. [Read](https://go.dev/blog/simd-experiment) citeturn0view0

**3. An index doesn’t guarantee a cheap DISTINCT**
DBOS found that discovering active queue partitions with `SELECT DISTINCT` scanned every matching workflow, slowing as queues deepened; a recursive CTE that seeks successive unique keys avoided that scan. A useful reminder to benchmark backlog-heavy cases, not just many small partitions. [Read](https://www.dbos.dev/blog/postgres-select-distinct-does-not-scale) citeturn1view0

**4. CI logs became an account-takeover surface**
A now-fixed SourceHut vulnerability let malicious terminal hyperlinks in build output execute JavaScript when someone viewed the logs, potentially exposing deployment credentials. Audit log-to-HTML converters as security boundaries; the writeup identifies fixes in `ansi2html` 1.9.4 and `builds.sr.ht` 0.105.1. [Read](https://blog.arusekk.pl/posts/srht-account-takeover/)

**5. Developer environments with packages fetched on demand**
The omnibin prototype uses a FUSE filesystem and Nix cache metadata to expose binaries immediately, fetching their archives only when needed. It’s an interesting approach for disposable development or agent environments that otherwise require large, prebuilt tool images. [Read](https://fzakaria.com/2026/09/24/every-package-is-already-installed)
