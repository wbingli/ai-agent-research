# Tech Digest — 2026-11-10

**1. AI proofs reach Signal’s cryptographic implementation**
AlphaProof Code uses AI agents and Lean to prove specified security properties of Signal’s compiled cryptographic code, with humans reviewing the specifications. The promising pattern is machine-checked evidence—not trusting an agent’s verdict—and broader deployment still needs research. [Read](https://deepmind.google/blog/introducing-alphaproof-code/)

**2. .NET 11 brings practical backend upgrades**
The release adds C# union types, built-in Zstandard compression, and reproducible container publishing; Runtime Async remains preview. For platform teams, these are concrete opportunities to simplify application code and build pipelines without confusing experimental features with production defaults. [Read](https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/)

**3. Valid email rejected over missing DMARC**
Mythic Beasts reports Microsoft rejected mail despite valid SPF and DKIM, while adding a `p=none` DMARC record restored delivery for affected domains. The operational lesson: monitor destination-specific rejection rates, not just whether your mail server successfully sends. [Read](https://www.mythic-beasts.com/blog/2026/11/09/microsoft-are-rejecting-your-mail/)

**4. Give coding agents current browser knowledge**
Modern Web Guidance supplies targeted skills and compatibility data to steer agents toward native browser capabilities instead of legacy JavaScript workarounds. It offers a practical way to improve generated frontend code through maintained engineering guidance rather than bigger prompts. [Read](https://github.com/GoogleChrome/modern-web-guidance)

**5. One tarball, eight different extraction results**
A deliberately unusual archive produces eight different outcomes across extraction tools, exposing ambiguity around hard links and extended headers. For build and packaging teams, it’s a reminder to test archive handling across platforms rather than assume identical inputs yield identical files. [Read](https://stoppels.ch/2026/11/07/the-hardest-tarball.html)
