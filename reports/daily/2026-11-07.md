# Tech Digest — 2026-11-07

**1. Alpine SSH bypass: patch and restart**
Alpine warns that certain non-PAM SSH configurations allow password-free access to key-only accounts when another account has a qualifying password hash. Update OpenSSH and restart `sshd`; installing the package alone leaves the running daemon vulnerable. [Read](https://www.alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/)

**2. GitHub separates Git storage from coordination**
GitHub’s new architecture puts immutable objects in blob storage, coordinates reference updates separately, and isolates compaction from request-serving compute. Still in limited private preview, it offers a useful distributed-systems lesson: scale bulk data independently from the small amount of state that needs agreement. [Read](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)

**3. Coding benchmarks need changing requirements**
MaxxBench modifies familiar coding tasks and finds agents sometimes favor imagined grading rules over explicit requirements—even undoing correct changes. For agent evaluations, test requirement revisions and independently measure behavior rather than trusting an agent’s self-reported success. [Read](https://maxxbench.unlap.ai/research/why-maxxbench/)

**4. Lock down transitive GitHub Actions dependencies**
Workflow dependency lockfiles pin action dependencies—including transitive ones—to reviewed commits, reducing exposure to moved tags. Reusable workflow calls still need explicit SHA pinning: the lockfile is not a blanket guarantee for every CI input. [Read](https://docs.github.com/en/actions/concepts/security/workflow-dependency-lockfiles)

**5. A practical GeoDNS migration off AWS**
Vincent Bernat moved his blog’s CDN and geographic DNS routing to Bunny, using per-query JavaScript to return nearby healthy servers. The writeup is useful for edge-serving design: it covers routing, image-format cache separation, and the tradeoff of missing HTTP/3 support. [Read](https://vincent.bernat.ch/en/blog/2026-bunny-geodns)
