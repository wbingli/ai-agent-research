# Tech Digest — 2026-10-04

**1. Aurora joins live data with the data lake**
Aurora PostgreSQL now embeds DuckDB to query Iceberg and Parquet alongside transactional data without copying it into the database. This could remove reverse-ETL plumbing for dashboards and agents that need both live and historical context. [Read](https://aws.amazon.com/blogs/aws/amazon-aurora-postgresql-now-supports-direct-querying-of-apache-iceberg-and-parquet-data-in-your-data-lake/)

**2. Clef separates AI decisions from text generation**
Cloudflare’s open-source Clef models return typed classifications with probabilities and support reinforcement-learning customization. My takeaway: evaluate specialized decision models for routing and escalation before putting a general-purpose LLM on every request. [Read](https://blog.cloudflare.com/clef-decision-models/)

**3. A fake client project hides a Git-hook attack**
A consultant received a Dropbox project folder containing a malicious `post-checkout` hook, then instructions to switch branches to find an NDA. The lesson: treat supplied repositories containing `.git` metadata as executable, untrusted material—not harmless documents. [Read](https://frankwiles.com/posts/i-got-targeted/)

**4. Iroh reuses BitTorrent discovery for verified transfers**
Iroh’s experimental content-discovery system combines BitTorrent’s Mainline DHT with an address-index service and BLAKE3-verified downloads. The useful architecture distinction: discovery finds potentially untrustworthy peers; independent content verification decides what bytes to accept. [Read](https://www.iroh.computer/blog/iroh-global-content-discovery)

**5. Local video search finds moments, not just files**
SCM combines local visual embeddings, OCR, and Whisper transcripts to retrieve specific shots or spoken lines on macOS. Its separation of semantic search from literal text matching is a useful design reference for media-search teams. [Read](https://github.com/allenv0/SCM)
