# Tech Digest — 2026-08-04

**1. Keyv and related npm packages compromised in supply-chain attack**
Attackers used a maintainer’s compromised GitHub account to publish credential-stealing, worm-capable releases with valid CI provenance. Engineering teams should audit recent installs, rotate exposed npm/GitHub/cloud credentials, and treat signed provenance as only one layer of trust. [Read](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack)

**2. Mistral releases Shieldstral for adaptable multimodal moderation**
This open-weight 3B model evaluates text and images against plain-language policies supplied at inference time, avoiding retraining for each product’s safety taxonomy. It offers teams a deployable, Apache-2.0 guardrail that can run on a single 16GB GPU. [Read](https://mistral.ai/news/shieldstral/)

**3. Cloudflare previews a hybrid runtime for AI agents**
`@cloudflare/computer` gives each agent a filesystem, shell, browser, and tools while dynamically placing work in lightweight isolates or Linux containers. The design targets better cost and concurrency than assigning every agent a permanently running container. [Read](https://blog.cloudflare.com/cloudflare-computer/)

**4. FFmpeg 9.0 expands modern media acceleration and HDR support**
The “Lei” release adds ProRes RAW via VideoToolbox, APV and v360 Vulkan acceleration, animated WebP decoding, Dolby Vision layer splitting, and broader HDR metadata handling. Media-platform teams gain more hardware-offload paths and richer delivery-format support, but should note removed legacy CELT and old NVENC support. [Read](https://github.com/FFmpeg/FFmpeg/blob/n9.0/Changelog)

**5. Passkeys expose new takeover paths when implementation details fail**
Unit 42 shows how malware on an already-compromised endpoint can abuse onboarding, recovery, and device-trust flows in synced passkey systems, including bypassing user verification and extracting keys. Security reviews must cover the full credential lifecycle—not just the cryptography—and verify relying-party enforcement of user-verification signals. [Read](https://unit42.paloaltonetworks.com/passwordless-authentication-security-risks/)
