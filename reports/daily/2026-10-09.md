# Tech Digest — 2026-10-09

**1. Deno joins Cloudflare—and sets migration deadlines**
The Deno team is joining Cloudflare: Deno Deploy will shut down in six months, and team-led runtime development ends after one more year of fixes and security updates. Teams using either should start migration planning as development shifts toward Workers, Durable Objects, and celld. citeturn0view0 [Read](https://deno.com/blog/cloudflare)

**2. Shorter TLS certificates need a renewal audit**
Let’s Encrypt switches its default certificate lifetime to 64 days on February 10, 2027, with staging available October 14, 2026. Check ACME Renewal Info support, remove hard-coded renewal schedules, and test certificate deployment and reloads—not just issuance. citeturn0view1 [Read](https://letsencrypt.org/2026/10/07/64-day-certs.html)

**3. A smaller model for decisions, not conversation**
Microsoft-Decision-1 scores predefined choices in a single pass, targeting routing, classification, and agent workflow control rather than text generation. My takeaway: benchmark specialized decision models for latency-sensitive paths instead of sending every small decision to a general-purpose LLM. citeturn0view2 [Read](https://commandline.microsoft.com/microsoft-decision-1-model-foundry/)

**4. An agent-driven Rust rewrite—with verification doing the heavy lifting**
Prime Intellect’s rewrite used separate implementation, review, and verification agents, plus differential tests covering terminal output, transcripts, and protocols. The useful lesson is the verification setup, not the swarm size: internal use still uncovered gaps that required follow-up work and human review. citeturn0view3 [Read](https://www.primeintellect.ai/blog/prime-agent-rust)

**5. Unison opens its distributed application platform**
Unison Cloud is now MIT-licensed, including its worker, API server, and UI; it combines typed service communication, distributed batch jobs, and storage backed by DynamoDB and S3. It’s an architecture worth studying for language-level distributed computing, though adopting it means embracing Unison rather than simply replacing a container orchestrator. citeturn1view0 [Read](https://www.unison-lang.org/blog/unison-cloud-open-source/)
