# Tech Digest — 2026-08-28

**1. Tolerating full cloud outages with Monzo Stand-in**
Monzo built a deliberately separate backup banking stack on GCP for its AWS-based primary platform, preserving critical payments and account actions during a major outage. Its reduced feature set, independent services, and eventual-consistency tradeoffs offer a pragmatic blueprint for true cloud-failure resilience. [Read](https://monzo.com/blog/tolerating-full-cloud-outages-with-monzo-stand-in)

**2. Saving 100 terabytes in Cloudflare’s DNS cache**
Five Rust data-layout changes cut each cache entry’s memory footprint by more than half across 250 billion entries, freeing roughly 100 TB while also improving inserts and lookups. It is a sharp reminder that at hyperscale, type choices, allocation count, and memory locality are infrastructure strategy—not micro-optimization. [Read](https://blog.cloudflare.com/dns-cache-memory-optimization-1111/)

**3. When a rumor is enough to generate an exploit**
An OCaml maintainer saw live probes within minutes of opening a security-fix PR and found that agents could independently discover and weaponize the bug from only a broad hint. Engineering leaders should assume disclosure-to-exploitation windows are collapsing and redesign patching, embargo, and release processes accordingly. [Read](https://anil.recoil.org/notes/rumour-is-the-exploit)

**4. Agent swarms are a distributed-systems problem**
Chroma argues that concurrent agents editing shared knowledge need specialized concurrency control because an aborted agent transaction discards costly reasoning, not milliseconds of deterministic computation. The useful design objective becomes preserving reasoning “goodput,” not merely applying textbook retries and isolation. [Read](https://www.trychroma.com/engineering/transactions)

**5. Turning LLM memory into program analysis**
Lemmalog models an agent’s knowledge as derived facts with provenance, incremental evaluation, and retractions rather than retrieving loosely related conversation fragments. This approach is especially compelling for long-running investigations where one invalidated assumption must also invalidate every conclusion that depended on it. [Read](https://pwning.systems/posts/llm-memory-program-analysis/)
