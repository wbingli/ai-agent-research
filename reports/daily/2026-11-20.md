# Tech Digest — 2026-11-20

**1. PostgreSQL 19 targets production pain points**
PostgreSQL 19 adds concurrent table repacking, query-plan stabilization, and explicit read-your-writes coordination on standbys. These target three familiar operational problems: table bloat, plan regressions, and stale replica reads. [Read](https://www.postgresql.org/about/news/postgresql-19-released-3449/)

**2. Inkling 2 Mini brings looped reasoning to local models**
Thinking Machines released an open-weights model that reuses its middle layers three times per token, with a reported memory footprint around 20GB. It offers an interesting local coding-agent candidate, but extra reasoning passes do not erase the factual-knowledge limits of a smaller model. [Read](https://thinkingmachines.ai/news/inkling-2-mini/)

**3. Valkey replaces skiplists with cache-friendly B+ trees**
Valkey 9.2’s sorted-set redesign reduced per-member memory overhead by 36–43% in a five-million-member test—not total database memory. The useful engineering lesson: contiguous storage and fewer pointer hops can matter as much as algorithmic complexity. [Read](https://valkey.io/blog/from-skiplist-to-b+tree/)

**4. Signal pushes back on OS-level AI screen capture**
Signal is adding screenshot-based protections against mobile AI agents reading private conversations, while acknowledging gaps such as filesystem access. For application teams, the warning is clear: encrypted transport alone does not protect data once an OS agent can observe the endpoint. [Read](https://signal.org/blog/protecting-your-privacy/)

**5. Connecting Raft proofs to real implementation traces**
Antithesis combined AI-assisted modeling, formal proofs, and fault-injected trace validation to uncover bugs in etcd and HashiCorp Raft. This is an early, human-guided research workflow: the proofs cover selected safety properties of patched models, not all production code or liveness. [Read](https://antithesis.com/blog/2026/verifying-formal-models/)
