# Tech Digest — 2026-09-23

**1. Cloudflare makes HTTP Vary configurable**
Cache Rules now support normalizing negotiation headers, preserving exact values, or bypassing cache when variation is unpredictable. For APIs and media delivery, this addresses the trade-off between serving the wrong representation and fragmenting the cache into barely reusable entries. **2. A routing hijack became a malicious software update**
An analysis of the Softaculous attack traces how BGP hijacking and a fraudulent TLS certificate enabled malicious Virtualizor updates; forging the expected origin ASN let the route remain RPKI-valid. The engineering takeaway: HTTPS and origin validation alone are not sufficient safeguards for an update pipeline. [Read](https://blog.apnic.net/2026/09/22/latest-bgp-hijack-targets-hosting-software-vendor/) citeturn0view4

**3. AI capability is getting cheaper—but measure your own tasks**
Epoch AI estimates that the cost of fixed performance across five benchmarks fell roughly 47% per quarter, while warning that benchmark gains do not equal useful work. My takeaway: periodically re-evaluate model routing against production tasks rather than assuming yesterday’s model remains the best value. [Read](https://epoch.ai/publications/the-plunging-price-of-thought) citeturn0view2

**4. Apple’s LensVLM reads compressed pages, then zooms in**
The 9B vision-language model scans compressed images of text and uses learned tools to expand only relevant pages. It offers a concrete research direction for document-heavy AI systems: selective detail rather than processing every page at full resolution. [Read](https://huggingface.co/apple/LensVLM-9B) citeturn0view1

**5. GPU-backed streaming inside VMs, without API translation**
Experimental virtio-nvgpu forwards NVIDIA driver operations between KVM guests and the host, retaining unmodified guest libraries for Vulkan and NVENC. Its reported near-native rendering results make it worth watching for shared-GPU streaming infrastructure—not treating as production-ready evidence yet.
