# Tech Digest — 2026-08-07

**1. OpenAI says its next model may reach “critical” cyber capability**
OpenAI says preliminary tests cannot rule out an upcoming model autonomously finding and exploiting zero-days in hardened systems, and is escalating safeguards and external testing. Security leaders should treat frontier models as a rapidly changing part of both the threat model and defensive toolkit. [Read](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/)

**2. A missing tenant boundary exposed 181,874 AI-recorded meetings**
A researcher found that any authenticated tl;dv user could query meetings across all customer accounts, including live conference IDs—a stark example of why authorization must be enforced server-side on every multi-tenant data path. [Read](https://bobdahacker.com/blog/tldv-hack)

**3. Rebuilding PostgreSQL’s query engine for analytical speed**
pgrust reports up to 300× PostgreSQL’s ClickBench performance by combining vectorized batches, operator fusion, and SIMD, with the new query engine accounting for roughly 10× of the gain. The implementation is a useful blueprint for reducing CPU and memory-bandwidth overhead in data systems. [Read](https://malisper.me/how-we-made-postgres-hundreds-of-times-faster-the-query-engine/)

**4. Managing AI coding costs without throttling adoption**
Databricks outlines a practical control plane for enterprise coding agents: continuously evaluate price/performance, preserve model and harness flexibility, route work through gateways, and keep per-user spend inside a predictable envelope. [Read](https://www.databricks.com/blog/managing-ai-coding-costs-scale)

**5. An agent-first browser built on V8 isolates**
Kitesurf replaces heavyweight per-agent Chromium sessions with a stateless browser designed for model-readable interaction on Cloudflare Workers, using WebAssembly, Durable Objects, and worker RPC. It points toward cheaper, denser browser automation infrastructure for large agent fleets. [Read](https://blog.cloudflare.com/kitesurf/)
