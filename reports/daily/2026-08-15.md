# Tech Digest — 2026-08-15

**1. DeepSeek Harness makes every agent capability a plugin**
The open-source developer preview makes models, tools, skills, sandboxes, storage, scheduling, loops, and UI swappable, while an append-only session log supports inspection, replay, forking, and search. It is a strong reference architecture for teams building observable, composable agent platforms. [Read](https://deepseek.com/harness/en/)

**2. TLA+ catches a production-grade registry deletion race**
Depot used an agent to derive a TLA+ model for its registry garbage collector; exhaustive model checking then found an interleaving that tests and reviews missed and that could delete live data. This is a practical blueprint for adding formal verification to high-risk distributed workflows without hand-writing every specification. [Read](https://depot.dev/blog/tla-verification)

**3. DuckDB adds asynchronous I/O for remote data**
DuckDB 2.0 will asynchronously read Parquet and CSV so worker threads can process data instead of blocking on S3-style remote fetches. The change reflects DuckDB’s shift from local SSD analytics toward data-lake and server deployments where request concurrency determines usable bandwidth. [Read](https://duckdb.org/2026/07/31/asynchronous-io)

**4. Bluesky’s Jetstream v2 unifies historical replay and live streaming**
Jetstream v2 serves filtered, compressed network archives over HTTP, then hands consumers to a live WebSocket stream without gaps or server-side cursor state. This design simplifies backfills, downtime recovery, and large-scale event analysis while keeping the infrastructure open-source and self-hostable. [Read](https://atproto.com/blog/introducing-bluesky-protocol-services)

**5. A Codex optimization loop produces a 232× faster GPU kernel**
A contest entrant used an agent-friendly benchmark-and-submit loop to optimize batched QR decomposition, placing 12th of 183 with a reported 232× speedup over baseline. The lesson for engineering leaders is that tight, automated correctness and performance feedback can turn coding agents into effective systems-optimization researchers. [Read](https://sankalp.bearblog.dev/autoresearch/)
