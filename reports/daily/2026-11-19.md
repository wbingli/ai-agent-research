# Tech Digest — 2026-11-19

**1. Nginx flaws warrant an edge-infrastructure review**
Researchers report five configuration-dependent remote-code-execution flaws, plus a Linux kernel exploit chain that escaped a container in testing. Review exposed proxies against the advisory: disabling HTTP/2 addresses only two paths, not the entire vulnerability set. [Read](https://xint.io/blog/nginx2root-remote-code-execution)

**2. PostgreSQL 19 targets production maintenance pain**
PostgreSQL 19 adds concurrent table repacking, query-plan advice, and logical-replication setup without the previously required restart in many deployments. Worth evaluating for write-heavy services where bloat cleanup and unpredictable query plans create operational work. [Read](https://www.postgresql.org/about/news/postgresql-19-released-3449/)

**3. DynamoDB APIs, your choice of database**
AWS released ExtendDB 1.0, an open-source DynamoDB-compatible adapter supporting PostgreSQL, SQLite, Cassandra, and MongoDB. Its SQLite-backed development package offers a concrete starting point for local testing and CI without an external database. [Read](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-extenddb-1-0/)

**4. Identical model weights don’t guarantee identical RL behavior**
Google’s Tunix work aligns floating-point execution across sampling and training to produce bitwise-identical token log probabilities, verified across 64 TPU chips. Engineering takeaway: check numerical consistency between execution paths before blaming unstable reinforcement learning on the algorithm. [Read](https://developers.googleblog.com/unlocking-stable-on-policy-rl-on-tpu-with-bitwise-zero-traininference-mismatch/)

**5. SQLite shards power a production blob store—with tradeoffs**
Zerodha’s Blobasaur combines SQLite shards, batched writes, compression, and Redis-compatible clients for low-latency preference storage. The useful architecture lesson includes its limits: no automatic failover yet, and production durability settings can lose recent commits after an OS crash. [Read](https://zerodha.tech/blog/high-performance-distributed-blob-storage/)
