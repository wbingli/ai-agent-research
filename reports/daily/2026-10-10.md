# Tech Digest — 2026-10-10

**1. Telegram Desktop’s one-click account takeover**
A researcher chained a local IPC parsing flaw with an unguarded file-sending feature to steal files and login sessions; the report identifies 7.2.9 as the fix. Check desktop deployments—not the iPhone app—and treat internal URI handlers as security boundaries. [Read](https://beaksec.github.io/posts/telegram-desktop-one-click-account-takeover/)

**2. AI agents get enforceable permission boundaries**
Microsoft’s generally available Execution Containers enforce file and network permissions outside the agent’s control, with process sandboxes across Windows, macOS, and Linux. The useful distinction: constrain what generated code can actually do, rather than trusting instructions to keep it safe. [Read](https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/)

**3. Production coding agents need a review system**
Cockroach Labs describes a five-month workflow separating planning, implementation, review, and merge gates—with human approval required after the first experimental week. The transferable lesson: review plans before code, keep changes small, and preserve audit trails rather than optimizing only for throughput. [Read](https://www.cockroachlabs.com/blog/experiment-running-hospital-code/)

**4. DuckDB’s faster S3 reads expose the real bottleneck**
A DuckDB 2.0 alpha benchmark shows how separate download and compute workers overlap network waits with Parquet decoding. Large-file queries improved, but tiny-file workloads barely benefited—a useful reminder that engine upgrades do not fix poor data layout. [Read](https://motherduck.com/blog/why-duckdb-20-is-faster/)

**5. NumPy accelerates binary search by batching work**
NumPy 2.5’s redesigned `searchsorted` advances independent searches together, reporting up to 25× faster performance in the authors’ benchmarks with constant extra memory beyond the output. Worth benchmarking for histogram and interval-lookup pipelines; the broader lesson is to hide memory latency before adding threads. [Read](https://blog.scientific-python.org/numpy/searchsorted/)
