# Tech Digest — 2026-10-20

**1. Compromised certificate keys expose HTTPS trust risks**
Eight eMudhra intermediate-certificate keys were compromised, enabling fraudulent HTTPS certificates; Mozilla blocked them through Firefox’s remote revocation system. Check applications using Mozilla-derived trust stores too: they may need the separate NSS update rather than receiving Firefox’s automatic protection. [Read](https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/)

**2. AI code reviews got 68% cheaper—with a quality catch**
Cloudflare cut review costs through shared prompt prefixes, fewer wasted tool calls, and model/effort tuning. The important caveat: performance reviewers missed more real issues at medium effort, so measure useful findings alongside cost and latency. [Read](https://blog.cloudflare.com/obsessive-inference-optimization/)

**3. Workflow “completed” didn’t always mean work executed**
Jepsen found Orkes Conductor could lose workflows or report completion without running their tasks; version 5.5.6 patches all serious safety issues identified. A useful reminder to test orchestration failure modes and make task side effects safe under concurrent retries. [Read](https://jepsen.io/analyses/orkes-conductor-5.3.2)

**4. DeepSeek opens its inference framework**
DeepInfer exposes technology behind DeepSeek’s production services, but this release provides offline inference—not a complete turnkey serving system. Worth studying for large-scale inference architecture, with that deployment boundary in mind. [Read](https://github.com/deepseek-ai/DeepInfer)

**5. Voxtral 3 connects speech and tools in one pipeline**
Mistral combines transcription, reasoning, tool calls, and speech generation in a real-time voice-agent SDK, available through its EU-hosted API or self-deployment. For teams building voice interfaces, it offers an integrated option to evaluate instead of stitching the entire pipeline together. [Read](https://mistral.ai/news/voxtral-3/)
