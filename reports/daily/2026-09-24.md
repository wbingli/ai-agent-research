# Tech Digest — 2026-09-24

**1. AI agents build the tools that make audits better**
Trail of Bits used agents to build a decompiler, static analyzer, and Lean models for a Miden security audit, uncovering real vulnerabilities and producing 95 machine-checked proofs. The useful pattern: invest AI effort in reusable verification tools, not just more code-review comments. [Read](https://blog.trailofbits.com/2026/09/18/auditing-in-the-age-of-good-enough-ai/) citeturn1view1

**2. Go brings portable SIMD to backend hot paths**
Go 1.27’s experimental SIMD interface lets the same vectorized code target x86, ARM, and WebAssembly, with emulation where needed. Worth benchmarking for CPU-heavy data processing before maintaining separate assembly implementations—but the API remains experimental. [Read](https://go.dev/blog/simd-experiment) citeturn0view0

**3. Radicle’s private repositories weren’t private on the wire**
Radicle disclosed plaintext transport and broken peer authentication; its advisory says to stop private-repository network sharing and rotate secrets in previously transmitted repositories. The architecture lesson: signed content does not replace encrypted transport or authenticated peers. [Read](https://radicle.dev/2026/09/23/disclosure-of-vulnerability-in-network-protocol) citeturn1view3

**4. An agent’s sandbox can hold while its files leave**
A researcher reports that Meta’s Muse exported its session filesystem, including internal documentation and SSH key files, through a connected Google Drive account; he did not demonstrate a container escape or establish whether the keys were active. For agent platforms, this suggests testing readable-file scope and export permissions separately from sandbox isolation. [Read](https://mouse.dev/blog/muse-runtime-export/) citeturn2view0

**5. Parallel agents surface a biological discovery—not a finished breakthrough**
Anthropic reports that Claude agents identified a previously uncharacterized enzyme system, followed by human lab experiments; its biological function remains unknown. The transferable workflow is broad parallel search, aggressive candidate filtering, and independent experimental validation—not treating generated hypotheses as results. [Read](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) citeturn1view2
