# Tech Digest — 2026-11-12

**1. AWS puts realistic infrastructure inside the agent loop**
AWS Emulator runs local versions of 200+ services, with agent-written implementations checked against real AWS behavior. The useful lesson is the validation architecture—fidelity tests, security reviews, and deterministic merge gates—not a claim that emulation replaces production testing. [Read](https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html)

**2. Fast AI decisions without generating prose**
Google’s Gemini Decisions API scores predefined options across text, images, audio, and video, returning confidence scores rather than generated answers. It’s worth evaluating for model routing, content-policy checks, and escalation to human reviewers where latency and uncertainty matter. [Read](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)

**3. Rust 1.100 stabilizes the never type—with a migration wrinkle**
The `!` type can now be named anywhere, and `Infallible` becomes its alias. Older editions also change never-type fallback behavior, so teams upgrading should check inference-sensitive code rather than treating this as a purely additive release. [Read](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/)

**4. Apple isolates ambient sensing from the main OS**
Secure Exclaves process camera and microphone streams in hardware-isolated runtimes, exposing limited metadata during ambient sensing rather than raw recordings. The architecture offers a concrete privacy pattern: enforce data boundaries below the application layer, with secure indicators when raw sensor access becomes active. [Read](https://security.apple.com/blog/secure-exclaves/)

**5. A small CPython adaptation tests a different JIT path**
The experimental yk integration adds under 450 lines and beats CPython’s experimental JIT on eight of thirteen reported benchmarks. It is explicitly not production-ready, but shows how meta-tracing could improve existing interpreters without building an entirely new runtime. [Read](https://tratt.net/laurie/blog/2026/adapting_cpython_for_yk.html)
