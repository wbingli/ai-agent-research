# Tech Digest — 2026-10-01

**1. Cloudflare K2: event streams on object storage**
K2’s public beta provides durable, ordered event logs backed by R2, separating compute from storage without managing broker clusters. For event-heavy ad and analytics pipelines, the architecture is worth studying as an alternative to operating Kafka—not assuming drop-in compatibility. [Read](https://blog.cloudflare.com/cloudflare-k2-streams/)

**2. Pi Durable makes agent crash recovery explicit**
This experimental agent framework records tool-call intent before execution and retries interrupted calls only when the tool declares replay safe. The useful design lesson: restoring a conversation is not enough; recovery must also account for external side effects such as deployments. [Read](https://earendil.com/posts/pi-durable/)

**3. Turbopuffer outgrows its vector-first storage layout**
Turbopuffer is redesigning storage so vector search becomes a secondary index, addressing write amplification and constraints on text search and aggregations. It’s a concrete lesson in how an initially successful specialization can bottleneck broader workloads; v3 performance work and production rollout are still ahead. [Read](https://turbopuffer.com/blog/rip-vector-database)

**4. Clef targets bounded decisions instead of open-ended generation**
Cloudflare released Apache-2.0 decision models that return typed classifications with probabilities, alongside an RL fine-tuning platform. For ticket routing or content classification, this suggests evaluating a dedicated decision model rather than defaulting to a general-purpose LLM. [Read](https://blog.cloudflare.com/clef-decision-models/)

**5. Rust 1.99 expands C interoperability**
Rust can now define C-ABI variadic functions, extending its usefulness for native-library integration. The release also recommends avoiding `Box::leak` patterns that later deallocate memory—a worthwhile review target in unsafe code, despite no language-semantics change. [Read](https://blog.rust-lang.org/2026/10/01/Rust-1.99.0/)
