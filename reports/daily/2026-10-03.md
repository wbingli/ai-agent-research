# Tech Digest — 2026-10-03

**1. Aurora brings DuckDB to operational-data joins**
Aurora PostgreSQL can now join live transactional data with Iceberg and Parquet data in a lake, using embedded DuckDB rather than copying everything through reverse ETL. Worth evaluating for dashboards and services that need historical context without another synchronization pipeline. [Read](https://aws.amazon.com/blogs/aws/amazon-aurora-postgresql-now-supports-direct-querying-of-apache-iceberg-and-parquet-data-in-your-data-lake/)

**2. Clef makes classification a first-class agent primitive**
Cloudflare released Apache-licensed Clef decision models that return typed classifications with probabilities, plus an RL fine-tuning platform. The useful architectural idea: evaluate specialized decision models for routing and escalation instead of asking a general-purpose LLM to generate every answer. [Read](https://blog.cloudflare.com/clef-decision-models/)

**3. A fake client project hid a Git-hook attack**
An attacker sent a developer a Dropbox project containing a malicious `post-checkout` hook, then asked him to switch branches to find an NDA; the hook would download and execute a binary. The takeaway: treat supplied repository folders—including their `.git` metadata—as executable content, not harmless documents. [Read](https://frankwiles.com/posts/i-got-targeted/)

**4. A Rust WebP decoder targets safety without a speed penalty**
The new `wpd` decoder combines Rust with optional handwritten SIMD, and its authors report faster decoding than libwebp on their test corpus. For media pipelines processing untrusted images, it is a candidate to benchmark—not a reason to assume either universal speedups or an entirely unsafe-free implementation. [Read](https://halide.cx/blog/wpd/)

**5. Pi Durable separates agents from terminal sessions**
Released alongside Pi 1.0, the experimental Pi Durable framework targets long-running agents, multiple human collaborators, and recovery from failures. It is worth studying if your agent architecture needs to outlive a single developer’s terminal process. [Read](https://earendil.com/posts/pi-durable/)
