# Tech Digest — 2026-10-02

**1. Aurora joins live transactions with data-lake history**
Aurora PostgreSQL now embeds DuckDB to query Iceberg and Parquet alongside operational data, without copying lake data into the database first. Worth evaluating for dashboards and agents that need both fresh transactions and historical context without another reverse-ETL pipeline. [Read](https://aws.amazon.com/blogs/aws/amazon-aurora-postgresql-now-supports-direct-querying-of-apache-iceberg-and-parquet-data-in-your-data-lake/)

**2. Clef makes AI routing a specialized task**
Cloudflare released open-source Clef decision models that return typed classifications and probabilities, plus an RL fine-tuning platform. For routing, escalation, and content classification, this offers an alternative to asking a general-purpose LLM to generate an answer your application must interpret. [Read](https://blog.cloudflare.com/clef-decision-models/)

**3. A fake client project hid an executable Git hook**
Frank Wiles describes a targeted attack using a Dropbox-delivered repository and a request to switch branches; its `post-checkout` hook would download and execute a binary. The practical warning: treat supplied repositories containing `.git` metadata as executable material, not harmless project documents. [Read](https://frankwiles.com/posts/i-got-targeted/)

**4. SequenceHash avoids ambiguous multi-field hashing**
Trail of Bits released SequenceHash and SequenceMAC, with Rust, Go, and Python implementations, to hash multiple values without ambiguous concatenation. A useful review prompt for authentication and integrity code: a strong hash does not fix an ambiguous input encoding. [Read](https://blog.trailofbits.com/2026/10/02/sequencehash-multihashing-for-the-rest-of-us/)

**5. Keep agent transcripts—not just the resulting code**
Quesma’s open-source Shipper collects coding-agent sessions into your own storage, making repeated failures and wasted work available for analysis. Its strongest engineering takeaway: turn sessions where developers corrected or reverted an agent into team-specific evaluations. [Read](https://quesma.com/blog/agent-session-transcripts-are-precious/)
