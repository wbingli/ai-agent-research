# Tech Digest — 2026-10-13

**1. AI coding pushes the bottleneck into infrastructure**
Anthropic replaced its monorepo’s Git backend with Scion, using server-side operations and tiered caches to handle agent-scale development. The useful lesson isn’t “replace Git”: redesign checkout and CI bottlenecks while retaining human review—its engineers still review every change request for Scion. [Read](https://www.anthropic.com/engineering/redesigning-source-control)

**2. WebMCP trades browser clicking for explicit tools**
WebMCP lets websites expose structured JavaScript tools to agents; Shopify reports faster, cheaper checkout execution in a small experiment. Worth evaluating for agent-facing products, but protection against malicious tools and representative end-to-end testing remain open challenges. [Read](https://blog.yoav.ws/posts/why_webmcp_matters/)

**3. Idle Macs become a distributed inference pool**
Apple’s Minions research aggregates unused Apple Silicon GPUs into a fault-tolerant inference platform. It explores using existing hardware when centralized GPU capacity is constrained—not a claim that desktop fleets replace production GPU clusters. [Read](https://machinelearning.apple.com/research/distributed-gpu-cloud)

**4. A practical post-quantum crypto checklist**
Filippo Valsorda’s updated guide recommends hybrid X25519+ML-KEM key exchange while keeping familiar defaults such as cloud KMS and HMAC-SHA-256. A useful starting point for reviewing crypto dependencies and migration plans, with explicit caveats for stricter compliance regimes. [Read](https://words.filippo.io/right-answers/)

**5. Continuous benchmarks make curl faster and smaller**
Ahead of curl 8.23.0’s planned October 14 release, its maintainer reports 20–30% faster URL parsing and a 28% smaller per-transfer handle. The engineering takeaway: persistent microbenchmarks expose incremental CPU and memory savings, even when most users won’t notice faster downloads. [Read](https://daniel.haxx.se/blog/2026/10/13/a-slightly-faster-slimmer-curl/)
