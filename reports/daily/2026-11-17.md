# Tech Digest — 2026-11-17

**1. Java4Shell: check your JVM fleet**
Researchers demonstrated remote code execution through OpenJDK’s optimized Base64 decoder on affected x86-64 CPUs with AVX-512 VBMI; ARM64 is unaffected. Prioritize patched runtimes, or use the disclosed `-XX:-UseBASE64Intrinsics` mitigation while upgrading. [Read](https://calif.io/java4shell/)

**2. GPT-6.2 shifts the cost–quality tradeoff**
OpenAI launched Astra and Sol, reporting stronger coding and multistep performance with fewer output tokens; Astra’s input/output token prices are 20% below GPT-6 Astra’s. Worth rerunning your own agent evaluations on cost per accepted result—not just benchmark scores. [Read](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

**3. Split inference delivers more tokens per watt**
Cerebras reports 5× throughput per megawatt versus a CS-3-only baseline on its production GPT-OSS-120B endpoint, without slower token generation, by moving prefill to AMD GPUs and retaining wafer-scale decode. The architecture transfers KV caches over RDMA: a concrete example of matching hardware to each serving stage rather than scaling identical accelerators. [Read](https://www.cerebras.ai/blog/cerebras-launches-disaggregated-inference)

**4. Redict ends development; maintainers recommend Valkey**
Redict is deprecated, with 7.3.6 its final release, after failing to build a sustainable community. If it’s in your stack, plan a migration; the broader dependency lesson is to evaluate maintainer capacity alongside licensing and feature compatibility. [Read](https://redict.io/posts/2026-11-17-redict-deprecated/)

**5. Faster Python startup needs more than lazy imports**
A measured Python 3.15 adoption cut CLI help startup roughly fourfold, but improved the TUI and MCP server only 20% and 15%. The useful playbook: profile import chains, guard against import-time side effects, and test real lazy execution separately from mocked tests. [Read](https://namegarage.com/blog/python-3-15-lazy-imports)
