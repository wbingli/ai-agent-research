# Tech Digest — 2026-11-14

**1. Security patch windows are shrinking**
Project Zero has replaced its “90 + 30” disclosure policy with a 90-day deadline, moving to 60 days on February 2, 2027, and 30 days on January 3, 2028. Its rationale: AI accelerates exploitation, so engineering teams need faster remediation and patch rollout—not just faster bug discovery. [Read](https://projectzero.google/2026/11/disclosure-policy.html)

**2. AI-built apps still need authorization testing**
Researchers found sensitive data accessible without login in Lovable apps using Supabase, including private messages and customer records; their sample does not establish a platform-wide leak rate. My takeaway: test database access controls directly rather than treating a working login screen as proof of security. [Read](https://www.crissyfield.de/research/lovable-en/)

**3. Rust 1.100 brings allocator control—and an upgrade caveat**
Rust 1.100 stabilizes core custom-allocator support for `Vec` and `Box`, plus broader use of the never type (`!`). Teams upgrading older-edition code should check the changed never-type fallback, which can break some previously compiling code. [Read](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/)

**4. Portable SIMD without hand-rewriting every kernel**
A Jane Street intern project uses an OxCaml DSL to compile the same parallel kernel for multiple architectures instead of maintaining instruction-set-specific C loops. It offers a useful design pattern for performance-critical services: express the computation at a higher level and let the compiler handle vectorization. [Read](https://blog.janestreet.com/writing-a-dsl-for-high-performance-parallel-programming-in-oxcaml/)

**5. DeepSeek V3’s architecture, small enough to inspect**
A 190-line pure-JAX implementation demonstrates DeepSeek V3 mechanisms, including latent attention and mixture-of-experts routing, with a small model trained on a MacBook Air. It is explicitly an educational architecture demo—not a frontier-model reproduction—making it useful for understanding the machinery without a large framework. [Read](https://github.com/Vaibhaav-Tiwari/deepseek-v3-jax)
