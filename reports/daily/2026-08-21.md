# Tech Digest — 2026-08-21

**1. Rust supply-chain attack compromised popular crates**
A compromised maintainer account republished `arrayref` and related crates with a dependency that downloaded a malicious payload. Rust’s response team removed the affected releases; teams should audit Cargo caches and lockfiles for the listed versions. [Read](https://blog.rust-lang.org/2026/08/20/supply-chain-attack-on-arrayref/)

**2. Expired DNS infrastructure exposed phone-routing metadata**
A researcher took control of abandoned nameserver infrastructure serving three `e164.arpa` country-code zones, revealing how forgotten DNS delegations can become long-lived control-plane vulnerabilities. It is a strong case for continuously auditing delegated zones—not just registered domains. [Read](https://lina.sh/blog/hijacking-e164-arpa)

**3. Waymo opens its autonomous-driving compute architecture**
Waymo describes an onboard, redundant heterogeneous system built for deterministic millisecond decisions, including a custom 5nm ASIC delivering over 1,000 TOPS for sensor processing and ML. The co-design of silicon, sensors, models, cooling, and failover is a useful blueprint for safety-critical edge AI. [Read](https://waymo.com/blog/2026/08/look-under-our-trunk/)

**4. Serving speech generation with sub-50 ms latency**
Nari Labs reports 10 requests per second with sub-50 ms p95 time-to-first-audio for Qwen3-TTS 1.7B on one H100, using open-loop tests and streamed audio validation. The open-source implementation shows how multimodal serving can optimize latency, throughput, and cost together rather than treating them separately. [Read](https://nari-labs.com/blog/qwen3-tts-speed-cost-frontier/)

**5. GitHub’s outage shows why autoscaling must observe sidecars**
A GitHub service scaled on host metrics while its Istio sidecar hit concurrency limits, illustrating how a healthy-looking component can hide saturation elsewhere in the request path. Engineering leaders should treat autoscaling policies as service-specific control systems and validate them with load tests and whole-path signals. [Read](https://surfingcomplexity.blog/2026/08/19/github-autoscaling-and-the-component-substitution-fallacy/)
