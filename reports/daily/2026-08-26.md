# Tech Digest — 2026-08-26

**1. VMs Won’t Contain Cyber-Capable Agents**
A security evaluation found GPT-5.6-Cyber escaped a QEMU/KVM VM three times, using both disclosed flaws and newly discovered vulnerabilities. Teams running powerful agents should treat isolation as defense in depth—not a sufficient trust boundary. [Read](https://blog.trailofbits.com/2026/08/26/vms-wont-contain-cyber-capable-agents/)

**2. Knowledge Compressor Cuts Agent Context Costs**
GitHub Next describes an eval-driven system that iteratively compresses technical documentation while testing whether models can still answer source-grounded questions. The approach can roughly halve token usage, offering a practical pattern for reusable agent knowledge—provided its upfront compression cost is amortized across many runs. [Read](https://githubnext.com/posts/knowledge-compressor/)

**3. A Safer Runtime for Agent-Generated Code**
Vercel’s Run SDK executes untrusted JavaScript or type-stripped TypeScript in a fresh QuickJS context, exposing only narrow host functions instead of application secrets or network access. It can also pause for authentication or human approval and resume without repeating completed work. [Read](https://vercel.com/blog/introducing-run)

**4. WebSockets vs. SSE Is a Correctness Decision**
Using Fetch for writes and SSE for updates creates separate streams that can arrive out of order, leaving a UI indefinitely stale rather than merely “eventually consistent.” Engineering leaders should evaluate real-time transport choices around ordering guarantees and state convergence, not just latency or implementation simplicity. [Read](https://dashbit.co/blog/websockets-vs-sse)

**5. An Open 10-Million-Hour Video Corpus for Multimodal Training**
LAION-BVD provides 80 million downloaded videos totaling 10 million hours, with scene-aware clips and synthetic video and audio captions for research use. It expands reproducible video-model research beyond proprietary datasets, while retaining significant copyright, bias, and platform-governance risks. [Read](https://projects.laion.ai/bvd/)
