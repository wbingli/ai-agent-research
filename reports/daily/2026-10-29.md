# Tech Digest — 2026-10-29

**1. Mistral Large 4 goes open-weight**
Mistral released its trillion-parameter multimodal model’s weights, reporting stronger coding performance and lower token usage than its preview. For teams needing deployment control, it’s a new self-hosting candidate—not a substitute for workload-specific cost and quality testing. [Read](https://mistral.ai/news/mistral-large-4-oss/)

**2. Alpine’s GitLab upgrade missed the actual security fix**
Alpine remained vulnerable after upgrading GitLab because its custom container lacked a required Ruby patch; it rebuilt the instance after attempted exploitation, without finding evidence of successful code execution. The operational lesson: verify patched dependencies inside the deployed artifact, not just the application version. [Read](https://alpinelinux.org/posts/GitLab-security-incident-CVE-2026-97229.html)

**3. GitHub is redesigning Git infrastructure for agent traffic**
GitHub’s new architecture emphasizes separating storage from compute and minimizing coordination, alongside an ongoing multi-region Azure migration. The useful takeaway for platform teams: agent-driven workload growth can demand architectural changes, not merely more capacity. [Read](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/)

**4. “AES-256” PDFs undermined by weak randomness**
Researchers found that MuPDF versions before 1.28.5 generated encryption keys with only nine bits of effective random state, enabling passwordless decryption. Audit document-generation dependencies and key generation—not just encryption labels; updating software cannot protect copies already distributed. [Read](https://v12.sh/blog/the-case-of-the-9bit-aes-key)

**5. Slack opens shared workspaces to custom coding agents**
The generally available Slack Code API lets agents create task-specific channels, show diffs, and expose progress for teammates to steer and approve. It offers a ready-made collaboration interface for internal agents; the expanded GitHub PR-review and merge experience is still forthcoming. [Read](https://slack.com/blog/developers/slack-code-api)
