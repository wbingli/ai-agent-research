# Tech Digest — 2026-08-14

**1. Google open-sources a compiler for encrypted AI inference**
Google’s HEIR compiler can convert pretrained models to run on homomorphically encrypted inputs, letting servers compute without seeing user data. It makes privacy-preserving AI more approachable for regulated and sensitive workloads, though compute cost remains the key trade-off. [Read](https://blog.google/security/how-google-is-making-private-ai-practical-with-homomorphic-encryption/)

**2. DeepSeek releases a fully pluggable agent harness**
DeepSeek Harness exposes models, tools, skills, sandboxes, storage, scheduling, and UI as swappable plugins, while recording execution in an append-only session log. The architecture is a useful reference for teams building observable, replayable agent platforms instead of tightly coupled demos. [Read](https://deepseek.com/harness/en/)

**3. Bluesky adds replayable network streams to Jetstream**
Jetstream v2 combines compressed historical archives with a live WebSocket tail, allowing consumers to recover from downtime or bootstrap filtered datasets without client-side backfills. Its stateless replay design is a practical pattern for operating large public event streams cheaply. [Read](https://atproto.com/blog/introducing-bluesky-protocol-services)

**4. DRAM remapping breaks protections above the memory controller**
A security researcher demonstrates how changing documented DRAM translation registers on older AMD CPUs can expose memory regions hidden even from the kernel. The work is a sharp reminder that isolation guarantees can collapse when lower hardware layers remain mutable. [Read](https://github.com/xoreaxeaxeax/skitter-creek-bath-salts)

**5. curl builds a pragmatic continuous performance lab**
The curl project now tracks throughput, allocations, and other metrics across builds using dedicated local hardware and simple scripts rather than waiting for ideal infrastructure. Engineering leaders can borrow the approach: establish a stable baseline early, automate graphs, and evolve the benchmark suite incrementally. [Read](https://daniel.haxx.se/blog/2026/08/14/curl-performance-2/)
