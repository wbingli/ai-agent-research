# Tech Digest — 2026-10-12

**1. Deno joins Cloudflare to make distributed apps portable**
The teams are bringing celld and workerd together to simplify self-hosting Workers and Durable Objects across machines. Worth watching for stateful services: the goal is a simpler deployment model without requiring Cloudflare hosting—not a completed migration path yet. [Read](https://blog.cloudflare.com/deno-joins-cloudflare/) citeturn1view0

**2. A signed cookie carried its own signing key**
A researcher disclosed a now-fixed Google DevSite vulnerability that chained an exposed signing secret with Python pickle deserialization into remote code execution. The engineering lesson: keep secrets and OAuth state server-side, separate keys by purpose, and remove executable serialization at client boundaries. [Read](https://simonkoeck.com/writeups/google-devsite-flask-session-pickle-rce) citeturn1view1

**3. Python JSON processing reaches 65.7 GB/s—with caveats**
Daniel Lemire’s benchmark combines free-threaded Python, SIMD parsing, and lazy field access on 64 cores; input was already decompressed in memory. For event pipelines, the useful takeaway is to avoid constructing unused objects and shared counters—not to expect that throughput end to end. [Read](https://lemire.me/blog/2026/10/12/parsing-json-at-tens-of-gigabytes-per-second-in-python/) citeturn1view2

**4. Meta’s Muse Wonder targets persistent, long-running agents**
Meta launched Muse Wonder with cross-conversation memory and sustained task execution, including check-ins before important actions. It’s a candidate for evaluating longer coding workflows, but benchmark leadership remains a vendor claim and additional safety evaluations are still forthcoming. [Read](https://research.meta.ai/blog/muse-wonder) citeturn1view3

**5. Run a larger-than-RAM LLM by streaming experts from SSD**
Janas keeps mixture-of-experts weights on disk and caches frequently used experts, demonstrating an 80B model on a 32 GB laptop. It suggests a lower-memory route to local inference, but the reported performance is hardware-specific and broader hardware coverage remains untested.
