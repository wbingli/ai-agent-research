# Tech Digest — 2026-09-15

**1. A public container image exposed production GitHub access**
Strix reports finding a long-lived token with admin access to Baseten’s product and GitOps repositories through a public container registry; Baseten restricted access and rotated the token. Audit old image layers and registry permissions—not just current source code—for credentials that can reach production. [Read](https://www.strix.ai/blog/baseten-harbor-github-pat-takeover)

**2. Jev replaces generated text with typed decisions**
TypeSafe’s early-access model takes unstructured input and returns predefined structured values with confidence scores, targeting fast automation rather than conversation. It’s an architecture worth evaluating for routing and classification, but guaranteed output types do not guarantee correct decisions. [Read](https://typesafe.ai/blog/introducing-system-one-models-and-jev)

**3. .NET 11’s performance gains come with reproducible benchmarks**
A detailed engineering tour covers eliminated allocations, locks, bounds checks, and other runtime overhead, with self-contained benchmarks comparing .NET 10 and 11. Use it to identify optimizations relevant to your backend workloads rather than assuming every service gets the same upgrade benefit. [Read](https://devblogs.microsoft.com/dotnet/performance-improvements-in-net-11/)

**4. Give coding agents boundaries in legacy systems**
Addy Osmani proposes risk zones: autonomy in isolated, well-tested code; characterization tests before changes in uncertain areas; and no unsupervised rewrites of authentication, billing, or permissions. The useful management shift is to allocate agent autonomy by blast radius and verification quality, not repository-wide enthusiasm. [Read](https://addyo.substack.com/p/brownfield-agentic-engineering)

**5. Separate search indexing from AI-training permission**
Cloudflare’s new setting lets sites disallow AI training without excluding participating mixed-use search crawlers; Apple, Google, and Microsoft have existing support or time-bound commitments. For ad-supported publishers, this offers more granular content controls, but enforcement depends on each operator’s actual support. [Read](https://blog.cloudflare.com/accountable-mixed-use-ai-crawlers/)
