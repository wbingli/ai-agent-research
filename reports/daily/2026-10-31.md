# Tech Digest — 2026-10-31

**1. Jepsen finds serious gaps behind ParticleDB’s ACID claims**
Testing uncovered 96 issues, many on a single node without injected failures—a reminder to demand correctness evidence alongside database benchmarks. Orkes says subsequent releases fix every reported issue, but Jepsen has not verified those releases. [Read](https://jepsen.io/analyses/particledb-1.1.4)

**2. A shared ChatGPT link crossed the sandbox boundary**
Researchers chained an unchecked cross-frame message handler with HTML injection to access private conversations; OpenAI fixed the issue on October 26. The engineering lesson: authenticate both message origin and sending window, and test interactions between otherwise isolated features. [Read](https://www.parameter.ai/labs/we-found-a-gap-at-openai)

**3. Reliable agents need enforcement, not more prompting**
Sentry’s Junior uses an egress proxy to inject credentials and enforce approved tool paths, while webhooks trigger responses to CI failures and review feedback. Human review remains part of the workflow—a concrete pattern for automating follow-through without letting agents approve their own PRs. [Read](https://cra.mr/a-little-determinism)

**4. Your “100% CPU” database may be waiting on memory**
A measured GROUP BY example improves cache locality with radix partitioning, reducing warm-run time from 3.6 to 2.7 seconds despite executing more instructions. Profile memory stalls before adding cores or assuming fewer operations means faster code. [Read](https://pivotlake.io/blog/its-the-memory-latency-stupid/)

**5. Redox brings ring-buffer I/O to userspace services**
Redox’s new interface uses shared submission/completion queues and shared data buffers to batch asynchronous requests without copying data between processes. It’s a useful architecture case study for reducing IPC overhead, though the team cautions that realistic-workload measurements still need more investigation. [Read](https://www.redox-os.org/news/nlnet-rb-summary/)
