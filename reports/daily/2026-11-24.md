# Tech Digest — 2026-11-24

**1. iTerm2: displaying a file could execute commands**
A researcher demonstrated how crafted terminal escape sequences turn image-protocol error responses into shell input; the report identifies iTerm2 3.7.9 as the fix. Particularly relevant to developer machines: viewing an untrusted README or log should not become code execution. [Read](https://ii4gsp.github.io/iterm2-rce/)

**2. Bonsai squeezes a coding agent into 5.9 GB**
PrismML’s Ternary Bonsai 2.5 27B keeps a 5.9 GB model footprint while reporting stronger multi-step tool use and fewer repetitive loops. Apple MLX and GPU support make it worth evaluating for private, on-device workflows—those capability gains are vendor-reported, not independent validation. [Read](https://prismml.com/news/bonsai-2-5-27b)

**3. Disk failures need more than restart tests**
Antithesis combined I/O errors with simulated power loss to uncover a bbolt failure that could leave an etcd node unable to reopen its store. The engineering lesson: test sequences of storage faults, not just isolated crashes, because cached state can hide durability failures. [Read](https://antithesis.com/blog/2026/nightmare-mode/)

**4. Hex breach exposes a dangerous deserialization chain**
Attackers reached remote command execution through crafted Erlang terms and error-reporting paths; Hex found no package tampering but cannot rule out database reads. Hex users should change passwords and reset 2FA, while platform teams should scrutinize “safe” decoders and logging code that dispatches on attacker-controlled types. [Read](https://hex.pm/blog/security-incident-on-hexpm)

**5. Lean plus differential testing finds Clojure edge cases**
A developer reports 17 previously unreported bugs using small Lean models, Java-collection comparisons, and reproductions against Clojure itself. The useful pattern is selective verification: prove compact arithmetic functions, then differential-test larger structures and the boundaries between mechanisms. [Read](https://s.conao3.com/blog/2026/e4f733)
