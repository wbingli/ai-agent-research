# Tech Digest — 2026-11-23

**1. Smaller local coding models, without the usual quality cliff**
Nari Labs reports that its 10.1 GB, 3-bit Qwen3.8-27B matches or exceeds BF16 on its tested coding-agent benchmarks. Promising for self-hosted agents, but it requires a custom llama.cpp fork—and long-context GPU memory is substantially larger than the model file. [Read](https://huggingface.co/nari-labs/Qwen3.8-27B-NariQ-GGUF)

**2. Signal pushes back on OS-level AI screen capture**
Signal is blocking screenshots on iOS 27 and detected AI screen capture on Android to keep conversations out of assistant pipelines, while acknowledging that filesystem access remains a gap. The architectural lesson: encryption alone cannot protect plaintext from privileged agents on the endpoint. [Read](https://signal.org/blog/protecting-your-privacy/)

**3. Read-after-write consistency isn’t enough**
Aerogramme’s mailbox work shows why distributed clients also need monotonic reads; Garage K2V added synchronous read repair to provide them. Its explicit separation of local state from synchronization is a useful design pattern for making concurrency easier to reason about. [Read](https://aerogramme.deuxfleurs.fr/blog/2026-quality-imap-part-2/)

**4. Your CI runner and YAML scanner can disagree**
GitHub Actions accepts malformed YAML that standards-compliant parsers reject, creating compatibility problems for workflow analysis tools such as zizmor. For CI tooling, test against actual runner behavior as well as the specification—successful execution does not establish valid syntax. [Read](https://yossarian.net/til/post/github-actions-accepts-invalid-yaml/)

**5. A data-structure swap cuts Jolt’s memory footprint**
Replacing persistent red-black trees with B+trees reduced peak process memory by 40% in Jolt’s large-collection benchmark, with better locality speeding many operations. Small incremental builds initially regressed, making this a useful reminder to benchmark medium-sized workloads and bulk-loading paths—not just headline scale. [Read](https://yogthos.net/posts/2026-11-23-b+trees.html)
