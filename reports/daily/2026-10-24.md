**2. AI-written proofs move beyond toy programs**
Anthropic and Theorem report machine-checked no-crash proofs for 239 test entry points across 123 libraries. This suggests a promising complement to fuzzing, not “bug-free software”: coverage is limited to selected entry points, bounded inputs, and modeled single-threaded RISC-V binaries. citeturn1view0 [Read](https://www.anthropic.com/research/formal-verification)

**3. How Cerebras pipelines giant models**
Cerebras explains how it keeps model weights in on-chip memory and passes activations between wafers, with different requests occupying different pipeline stages. The useful capacity-planning lesson: KV-cache space limits concurrency, while micro-batch size trades per-request latency against throughput. citeturn1view1 [Read](https://www.cerebras.ai/blog/how-we-deploy-trillion-parameter-frontier-models-on-cerebras)

**4. Wild expands its fast-linker footprint**
Wild 0.11.0 enables WebAssembly linking by default and adds enough GNU linker-script support to link Linux kernel modules. Worth evaluating for build pipelines, with explicit caveats: Wasm debug information remains unsupported, and the macOS port is not enabled by default. citeturn0view3 [Read](https://github.com/wild-linker/wild/releases/tag/0.11.0)

**5. Python scripts get dependency-aware type checking**
Astral’s experimental uv–ty integration checks scripts against their own inline dependency and Python-version declarations, even when these differ from the surrounding repository.
