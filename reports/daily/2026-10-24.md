# Tech Digest — 2026-10-24

**1. AI-written proofs move beyond toy programs**
Anthropic and Theorem report formal security proofs for executable artifacts from 123 open-source libraries. This suggests a promising complement to testing, not “bug-free software”: guarantees depend on bounded inputs and assumptions including single-threaded RISC-V binaries. [Read](https://www.anthropic.com/research/formal-verification)

**2. How Cerebras pipelines giant models**
Cerebras explains how it distributes model layers across wafers, keeping weights in on-chip memory and passing activations over Ethernet. The architectural takeaway: memory placement and interconnect traffic deserve as much attention as raw compute when designing low-latency inference. [Read](https://www.cerebras.ai/blog/how-we-deploy-trillion-parameter-frontier-models-on-cerebras)

**3. Distributed SQLite: recovery versus availability**
rqlite’s creator contrasts consensus-based replication with Litestream’s disaster-recovery approach: surviving a machine failure is different from avoiding the wait to restore it. A useful architecture check before adopting a cluster—decide whether you need recoverability or continued service, and understand that rqlite’s partitioned minority refuses writes. [Read](https://philipotoole.com/twelve-years-of-distributed-sqlite/)

**4. Wild expands its fast-linker footprint**
Wild 0.11.0 enables WebAssembly linking by default and adds enough GNU linker-script support to link Linux kernel modules. Worth evaluating for build pipelines, with explicit caveats: Wasm debug information remains unsupported, and the macOS port is not enabled by default. [Read](https://github.com/wild-linker/wild/releases/tag/0.11.0)

**5. Python scripts get dependency-aware type checking**
Astral’s experimental uv–ty integration checks scripts against their own inline dependency and Python-version declarations, even when these differ from the surrounding repository. That makes it relevant to automation-heavy teams maintaining standalone scripts without dedicated project environments. [Read](https://astral.sh/blog/uv-ty-integration)
