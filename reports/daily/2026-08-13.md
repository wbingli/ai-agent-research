# Tech Digest — 2026-08-13

**1. How Tailscale Helped Find the SQLite WAL-Reset Bug**
A six-month investigation into 19 corruption incidents uncovered a long-standing SQLite race despite a conventional single-writer design. It is a strong case study in debugging rare failures, preserving forensic evidence, and treating backups as production-critical code. [Read](https://tailscale.com/blog/sqlite-wal-reset-bug)

**2. Gemini 3.7 Flash Targets Coding and Agent Workloads**
The new workhorse model improves debugging, issue resolution, and multi-step tool use while launching at half Gemini 3.6 Flash’s original per-token price. Engineering leaders should re-benchmark agent workloads because the capability-cost curve is moving faster than annual model-selection cycles. [Read](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/)

**3. DeepSeek Harness Makes Every Agent Capability a Plugin**
This open-source developer preview turns models, tools, sandboxes, storage, scheduling, loops, and UI into swappable plugins, backed by an append-only session log for replay and inspection. The architecture offers a useful blueprint for avoiding vendor lock-in while making agent behavior auditable. [Read](https://deepseek.com/harness/en/)

**4. DRAM Scrambling Breaks Security Boundaries Below the CPU’s Defenses**
Researchers demonstrate that rewriting memory-controller address translations on AMD Family 16h can expose protected DRAM regions invisible to the kernel. The work is a sharp reminder that firmware and hardware layers beneath physical-address protections remain part of the trusted computing base. [Read](https://github.com/xoreaxeaxeax/skitter-creek-bath-salts)

**5. Kubernetes on Oxide: Integrations Shaped by Production Needs**
Oxide describes how customer deployments drove three provisioning paths plus networking, storage, and reconciliation work rather than one abstract integration. The broader lesson is to build platform extensions from real lifecycle bottlenecks and standard control-plane interfaces. [Read](https://oxide.computer/blog/kubernetes-on-oxide)
