# Tech Digest — 2026-11-25

**1. 1Password breach exposes the CI/CD trust boundary**
1Password says a compromised employee GitHub account enabled malicious backend changes and theft of some customer account metadata—not vault contents. The engineering takeaway: review who can move code into production, and watch for targeted account-recovery phishing. [Read](https://1password.com/blog/update-on-nov-2026-security-incident)

**2. Test disk failures—not just process crashes**
Antithesis explains storage fault injection covering power loss, torn writes, I/O errors, and latency-induced concurrency bugs. Use it as a checklist for testing whether your durability guarantees survive failures below the application layer. [Read](https://antithesis.com/blog/2026/nightmare-mode/)

**3. Formal methods find bugs in mature Clojure code**
A developer reports 17 previously unreported bugs using Lean for small arithmetic functions and differential testing for collections—not a proof of the entire runtime. The practical lesson: combine narrowly scoped proofs with executable counterexamples and reference implementations. [Read](https://s.conao3.com/blog/2026/e4f733)

**4. Hex incident: “safe” deserialization still allowed RCE**
Crafted Erlang structs enabled remote command execution on Hex’s servers; investigators found no evidence of package tampering but cannot exclude database reads. Hex users should change passwords, reset authenticator-based 2FA, and avoid package mirrors until the new signing system arrives. [Read](https://hex.pm/blog/security-incident-on-hexpm)

**5. Servo advances embedded video support**
Servo 0.8 adds video captions and subtitles, plus WebAudio nodes, while fixing a typed-array performance problem that hung Flutter web content. Worth tracking for embedded media interfaces, but WebGL2, WebGPU, and accessibility integration still require feature flags. [Read](https://servo.org/blog/2026/11/25/october-in-servo/)
