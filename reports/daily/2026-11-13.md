# Tech Digest — 2026-11-13

**1. Rust 1.100 adds dependency cooldowns**
Cargo can now delay adopting newly published packages, giving malicious releases time to be detected; the release also stabilizes core custom-allocator APIs. Worth evaluating for supply-chain defense, but cooldowns are opt-in and do not cover `cargo install`. [Read](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/)

**2. GGML 1.0 lands with inference-engine changes**
The release adds FP8 support, removes deprecated APIs, and improves execution across CUDA, Metal, Vulkan, and other backends. For teams embedding local inference, this is a reason to benchmark their actual workloads—and check API compatibility before upgrading. [Read](https://github.com/ggml-org/ggml/releases/tag/v1.0.0)

**3. Better planning beats retraining in a world-model experiment**
A researcher reports raising LeWM’s long-horizon Push-T success from 22% to 85% through subgoal planning and a demonstration-memory graph, without changing model weights. The harder test reaches only 56%: a useful reminder to separate planning bottlenecks from model quality and test beyond familiar trajectories. [Read](https://haddyalchaer.com/jepa)

**4. Smaller backend indexes through approximate answers**
A practical Go guide explains Bloom filters and other probabilistic structures, including their error guarantees and memory tradeoffs. The immediately useful pattern: skip expensive storage or network lookups when a Bloom filter says “definitely absent,” while verifying positive matches. [Read](https://antonz.org/probabilistic-data-structures/)

**5. FreeBSD live migration advances—with explicit safety gaps**
A working bhyve prototype combines dirty-page tracking with a source/destination commit handshake to move running VMs between hosts. It remains experimental: unauthenticated transport, incomplete compatibility checks, and unresolved fencing requirements make the writeup more useful as a distributed-systems design review than a deployment recommendation. [Read](https://gyptazy.com/blog/freebsd-bhyve-live-migration-support-rfc/)
