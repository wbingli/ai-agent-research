# Tech Digest — 2026-11-22

**1. PostgreSQL 19 tackles production pain points**
Concurrent table repacking reclaims space without blocking reads or writes, while new plan-advice extensions help stabilize query performance. These target two familiar operational headaches: table bloat and unexpected query regressions. [Read](https://www.postgresql.org/about/news/postgresql-19-released-3449/)

**2. AI-assisted proofs meet real Raft implementations**
Antithesis combined AI-generated models, fault injection, and trace validation to uncover bugs in etcd and HashiCorp Raft. A promising research workflow—not blanket verification: humans guided the work, and proofs cover selected safety properties of patched models, not all production code or liveness. [Read](https://antithesis.com/blog/2026/verifying-formal-models/)

**3. Image previews can hide a command-execution path**
Upload2Shell research shows how ordinary image-processing libraries can route disguised uploads into Ghostscript, where a font-loader flaw bypasses its internal sandbox. My takeaway for media pipelines: audit transitive decoders and isolate rendering workers rather than trusting file extensions. [Read](https://pwn.ai/upload2shell/research.html)

**4. Lock down privileged CI triggers across the organization**
Python security maintainers outline how to restrict GitHub Actions triggers that can expose secrets when workflows execute untrusted pull-request code or comments. Their rollout pattern—inspect what a policy would block, then enforce it—is a practical supply-chain hardening task. [Read](https://pyfound.blogspot.com/2026/11/de-fanging-dangerous-triggers-in-github.html)

**5. OpenAI proposes perplexity as a shared safety metric**
OpenAI published internal pretraining measurements and argued for using perplexity to inform shared safety standards. The important caveat for model evaluation: different datasets make cross-lab numbers hard to compare, so this is a proposal—not a standardized capability scoreboard. [Read](https://openai.com/index/perplexity-and-intelligence/)
