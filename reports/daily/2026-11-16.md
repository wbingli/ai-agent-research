# Tech Digest — 2026-11-16

**1. Optimizely scripts became a malware delivery channel**
Report URI found malicious code injected into customers’ experiment scripts, including those used by Zoom, GitLab, and Peacock; how attackers obtained write access remains unknown. The engineering lesson: trusted third-party JavaScript needs change monitoring and restrictive content-security policies, not just domain allowlists. [Read](https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/)

**2. Always-on agents need durable infrastructure—not endless loops**
Anthropic outlines an architecture built around durable events, timers, memory, permissions, and an outbox. Single-worker coordination, credential proxies, and resumable human approvals make this a useful blueprint for background agents rather than a promise of unrestricted autonomy. [Read](https://claude.com/resources/articles/building-always-on-agents)

**3. Rust nightly parallelizes more of compilation**
Rust’s compiler frontend now runs in parallel by default on nightly, accelerating type and borrow checking. Clean-build gains can be substantial, but incremental gains are smaller—benchmark your actual edit/build loop before projecting CI savings. [Read](https://blog.rust-lang.org/2026/11/16/enabling-parallel-frontend-on-nightly/)

**4. Protocol correctness needs more than reading the spec**
Aerogramme’s IMAP team uncovered incorrect query behavior through differential testing against Dovecot, then strengthened its email parser with structure-aware fuzzing and real-world messages. A practical backend-testing lesson: combine reference implementations, round-trip properties, and messy production inputs. [Read](https://aerogramme.deuxfleurs.fr/blog/2026-quality-imap-part-1/)

**5. Jiff 1.0 makes time zones an API concern**
Jiff’s Rust datetime library puts time-zone and daylight-saving behavior into its core abstractions, with an explicit commitment to long-term API stability. Worth evaluating for scheduling services where calendar arithmetic—not merely timestamps—drives correctness. [Read](https://burntsushi.net/jiff/)
