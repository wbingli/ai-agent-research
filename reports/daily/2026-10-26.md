# Tech Digest — 2026-10-26

**1. An inference-cache bug crossed tenant boundaries**
Cloudflare disclosed that a configuration mismatch and SGLang rejection-path bug exposed other customers’ data in 155 GLM-5.3 responses; the September incident is fixed. The operational lesson: test tenant isolation and oversized-request failures, not just successful HTTP responses. [Read](https://blog.cloudflare.com/kv-cache-exposure-remediation/)

**2. Compromised certificates expose a Mac CLI blind spot**
Apple blocks compromised eMudhra certificates in Safari and framework-based apps, but some macOS command-line tools can still trust them through a separate certificate store. Engineering teams should review developer-machine trust stores rather than assume browser protections cover Git and curl. [Read](https://support.apple.com/en-us/149555)

**3. GPT-6.1 Terra targets cheaper computer-use automation**
OpenAI’s new model emphasizes visual reasoning and desktop tasks, with standard API prices half those of GPT-5.6 Terra and GPT-6.1 Sol. Its vendor-reported improvements make it a candidate for workflow-specific evaluations—not proof that unattended automation is reliable. [Read](https://openai.com/index/introducing-gpt-6-1-terra/)

**4. Fix tool-call syntax before blaming the model**
Ubicloud reports that constrained decoding in vLLM 0.31 brings newer Kimi and DeepSeek models to full tool-schema adherence in its testing. That addresses malformed calls and retry overhead, not whether an agent chooses the right action. [Read](https://www.ubicloud.com/blog/fixing-tool-call-accuracy-in-vllm)

**5. Cap replaces webviews with a Rust GPU interface**
Cap’s recording app moved from Tauri webviews to GPUI after platform-specific browser bugs, while retaining its separate Rust media engine. It’s a useful architecture case study for media tools that need tighter rendering control without rewriting capture and encoding. [Read](https://cap.so/blog/rebuilding-cap-in-gpui)
