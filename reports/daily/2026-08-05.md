# Tech Digest — 2026-08-05

**1. Atlassian Rovo can exfiltrate tenant data through prompt injection**
Researchers show that malicious content can make Rovo leak Jira and Confluence data through its URL-retrieval tool—even with web search disabled and without human approval. Engineering leaders should treat agent tool access and outbound requests as security boundaries, not rely on UI-level feature toggles. [Read](https://www.promptarmor.com/resources/atlassian-rovo-exfiltrates-data)

**2. Cloudflare turns engineering standards into enforceable agent context**
Cloudflare built a governed “Codex” of structured RFC requirements that agents apply during design and code review; in four months, its reviewer flagged nearly 250,000 deviations and blocked 16,000 merges. The useful pattern is to make standards versioned, scoped, and machine-readable before asking AI to enforce them. [Read](https://blog.cloudflare.com/engineering-standards-enforcement/)

**3. Celld offers self-hosted, distributed Durable Objects without consensus**
Deno’s open-source daemon runs each object as a small SQLite database, uses S3-compatible storage for durable state and ownership, and coordinates nodes without a separate control plane or consensus service. It is a compelling architecture for naturally sharded workloads where replaceable compute and object-level failure isolation matter. [Read](https://github.com/denoland/celld)

**4. Meta’s Muse Code makes coding agents persistent and restart-safe**
Muse Code coordinates long-lived background agents and records model calls, tools, approvals, and edits in an append-only event log, enabling exact replay after crashes. That design directly addresses latency, repeated discovery, and resilience in long-running repository-scale agent workflows. [Read](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2)

**5. How Compiler Explorer runs a resilient, cost-efficient AWS fleet**
Compiler Explorer combines CloudFront, WAF, path-routed load balancing, blue-green deployments, and replaceable spot instances across many EC2 types, keeping durable state outside the workers. The writeup is a practical blueprint for lowering infrastructure cost while preserving rollback speed and tolerance for sudden capacity loss. [Read](https://xania.org/202608/how-compiler-explorer-runs-on-aws)
